# Project P.A. 11주차 구현 현황 발표 대본

## 1. 표지
안녕하세요. Project P.A. 11주차 구현 현황을 발표하겠습니다. 이번 발표는 코드 설명보다 실제로 어떤 게임으로 보이기 시작했는지, 그리고 남은 개발을 어떻게 정리할지에 초점을 맞췄습니다.

## 2. 게임의 방향
출발점은 동물의 숲 같은 생활형 게임에서 플레이어가 상점을 직접 운영하면 어떨까 하는 아이디어였습니다. 단순 판매만 반복하면 목적이 약해지기 때문에 NPC 관계, 경제 변화, 해금 기대감을 함께 묶는 방향으로 설계했습니다.

## 3. 핵심 루프
현재 핵심 루프는 아이템 확보, 상점 진열, 가격 책정, NPC 방문, 구매 판단, 매출 성장입니다. 이 흐름이 Project P.A.의 가장 중요한 플레이 경험입니다.

## 4. 구현 기능
현재 플레이어 이동과 HUD, 인벤토리/핫바, 스마트폰 UI, 상점 슬롯, 가격 조정, NPC FSM, 구매 판단 로직, 저장 구조와 자동화 도구까지 기본 연결이 진행되어 있습니다.

## 5. 시연 시나리오
시연은 마을 씬 진입부터 시작해서 인벤토리, 상점 진열, NPC 방문, 구매 결과, 스마트폰 화면 순서로 보여주는 것이 좋습니다. 실시간 시연이 불안정할 경우를 대비해 짧은 녹화본도 같이 준비하면 안전합니다.

## 6. 11주차 진행 위치
로드맵상 현재는 9~12주차 구간인 상점 매입 및 소비 로직 검증 단계입니다. 기능은 대부분 보이기 시작했고, 이제 저장/로드와 중복 생성, 건물 배치, NavMesh 같은 안정화 작업이 중요합니다.

## 7. 기술 설계
아이템은 정적 원형인 Item과 런타임 상태인 ItemInstance로 나누고, NPC 구매 판단은 PurchaseEvaluator 순수 함수로 분리했습니다. 저장은 v4 마이그레이션으로 친밀도와 고용 NPC의 FSM 상태까지 복구하는 방향입니다.

## 8. 아트 및 씬 구성
현재 B-01부터 B-12까지 건물 에셋을 준비했고, 우선은 임시 모델이라도 배치해서 게임 루프를 보이게 하는 전략을 쓰고 있습니다. 최종 아트 교체가 가능하도록 프리팹과 데이터 연결을 분리하고 있습니다.

## 9. 남은 문제
남은 문제는 건물 방향과 스케일, NPC 중복 생성, 저장/로드 안정성, 캐릭터 애니메이션, UI 완성도입니다. 각 문제는 자동 검증 도구와 공통 프리셋, 저장 마이그레이션으로 해결할 계획입니다.

## 10. 다음 계획
13주차에는 저장-종료-재실행-복원 데모를 완성하고, 14~15주차에는 가공 시스템과 레시피를 붙입니다. 16주차에는 조명, 오디오, 모델 배치를 정리해서 5분 연속 플레이 가능한 발표용 데모를 목표로 합니다.
