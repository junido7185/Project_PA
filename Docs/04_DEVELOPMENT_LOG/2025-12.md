## 세션 4 — 2025-12-30 · 건설 시스템 전면 개편 + 저장 시스템

### 작업 내용

**건설 시스템 2차 설계 (`Refactor`):**
- 기존 UI 팝업 방식 → "아이템을 핫바에 들고 설치" 방식으로 UX 전환
- `BuildManager.cs`에서 `GameManager.instance.money`를 직접 차감하는 방식 유지 (이 시점 기준)
- 건물 ScriptableObject(`BuildingData`) 도입으로 코드 없는 데이터 추가 지원

**JSON 저장 시스템 (`Feat`):**
- `SaveManager.cs` 초안: `File.WriteAllText` 기반 로컬 JSON 저장
- `SaveData.cs` DTO 정의: 플레이어 위치, 인벤토리, 건물 목록, 재화
- 건설 시 자원 소모 로직 연결 (인벤토리 → 차감 → 건설)

### 생성/수정 파일
- `BuildManager.cs` — 아이템 장착 방식 건설
- `BuildingData.cs` — 건물 ScriptableObject
- `SaveManager.cs` — JSON 저장/로드 초안
- `SaveData.cs` — 직렬화 DTO

### 메모
UI 팝업 방식이 직관적이지 않다는 걸 플레이테스트 중에 깨달았다. 핫바에 들고 설치하는 방식이 훨씬 자연스럽다. 저장은 일단 로컬 JSON으로 돌아가게 했는데 나중에 UGS Cloud Save로 전환할 계획 — 인터페이스로 추상화해야 할 것 같다.
