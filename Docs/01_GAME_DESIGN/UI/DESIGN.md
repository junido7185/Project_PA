# Project P.A. UI 스타일 (데모 첫날 경로)

작성 2026-11-02 · 코드 권위: `Assets/Scripts/UI/PAUiTheme.cs`(공용 토큰), `SmartphoneUI`(기본 3색).
첫 적용 화면: 제작 창(`CraftingUI` 런타임 패널). 다른 창(가방·폰·가격·보고서)은 이 문서를 기준으로 맞춰 간다.
참고 도구: impeccable(디자인 어휘·비평 기준, `~/.claude/skills/impeccable`) — 웹 전용 규칙은 Unity UGUI에 맞게 옮겨 쓴다.

## 1. 방향

- **아늑한 섬 생활 + 바로 읽히는 작업 화면.** 세계는 크림색 종이·청록 표지·나무 소품의 로우폴리 섬이다. UI는 그 위에 놓인 '현장 수첩'처럼 보이게 한다.
- 화면 모드는 *Operate*(과제를 끝내는 화면)다. 장식보다 읽기·선택·결과 확인이 먼저다. 색은 절제하고, 강조는 행동·선택·상태에만 쓴다.
- 1920×1080 기준(CanvasScaler 1920×1080, match .5)에서 3m 거리 TV/모니터로 읽힐 크기.

### 글자
- 서체: Jalnan2 SDF 하나(TMP 기본). 둥근 굵은 서체가 세계의 목소리다. 다른 서체를 섞지 않는다.
- 크기 단계: 창 제목 36 · 상세 이름 34 · 버튼 28 · 목록 이름 24 · 본문 20~21 · 보조 19 · 캡션 18(목록 상태 줄은 이름의 74%).
- 긴 이름·설명은 자동 크기(최소 본문 16)로 줄이고 넘치게 두지 않는다.

### 간격·모양·깊이
- 8px 격자: 묶음 안 6~8, 요소 사이 12~16, 창 안쪽 여백 24.
- 모든 면은 `PAUiTheme.RoundedSprite`(9-slice 둥근 모서리). 테두리 선·왼쪽 색 띠는 쓰지 않는다. (대화창 이름표·칸 종류 받침도 면이다. 예외: 오른쪽 위 알림 카드는 레퍼런스 06처럼 금색 테두리 = 금색 면 위 7px 안쪽 크림 면.)
- 깊이: 창 아래 같은 모양 그림자(아래로 10, 불투명도 .30). 색 후광·유리 흐림은 쓰지 않는다.
- 배경 딤: `rgba(10,18,20,.42)` — 세계는 보이되 창이 앞에 선다.

## 4. 글(카피)

- 존댓말 해요체, 짧게. 버튼은 하는 일을 말한다("만들기", "닫기").
- 막힌 이유와 풀 방법을 같이 말한다("광업 전문 분야를 선택해야 해요", "본사 승인 등급 2 필요 · 현재 0").
- 화면에 영어 데이터 문구·설계 메모를 내보내지 않는다(아이템 설명은 플레이어 문장으로: `PA_CraftingStationsSetup.PlayerCopy`).
- 이모지·유니코드 기호를 아이콘 대신 쓰지 않는다. 아이콘은 같은 카메라·조명으로 구운 아이템 렌더(`PA_DemoIconBake`)만 쓴다.

## 5. 움직임·입력

- 상태를 전할 때만 움직인다: 제작 성공 시 상세 아이콘 한 번 튀기(0.22초). 창 등장·목록 연출은 없다.
- 마우스: 행 클릭 선택 → [만들기]. 키보드: W/S·↑/↓ 선택 이동, Enter·Space 만들기, Esc 닫기. 창이 열린 동안 이동·점프 입력은 막힌다(`PlayerInputHandler.ModalOpen`).
