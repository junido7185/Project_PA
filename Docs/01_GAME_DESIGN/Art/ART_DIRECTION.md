# Project P.A. 아트 디렉션

## 핵심 시각 정체성

Project P.A.는 낮에는 동물 주민과 생활형 마을을 만들고 밤에는 유일한 잡화점을 운영하는 3D 코지 라이프 시뮬레이션이다. 화면은 작은 디오라마를 내려다보는 느낌, 손으로 만든 듯 둥글고 읽기 쉬운 실루엣, 따뜻한 저채도 재료를 기본으로 한다. 판매한 물건이 주민의 행동과 마을 풍경을 바꾼다는 차별점이 오브젝트의 배치와 사용 흔적으로 보여야 한다.

## 색상 팔레트

| 역할 | 권장 범위/예시 |
|---|---|
| 목재 기본 | 짙은 밤색 `#6B4529`, 중간 목재 `#9E6B3D`, 상자 목재 `#B88247` |
| 밝은 표면 | 크림 `#EDE1BD`, 모래·석재 `#C7B899` |
| 자연 | 잎 녹색 `#739E54`, 흙 `#4D3826` |
| 강조 | 러그 코랄 `#CC7861`, 꽃 분홍/노랑/보라를 작은 면적으로 사용 |
| 야간 발광 | 등불 황금 `#FFD473` |
| UI 성공/행동 | 기존 짙은 녹색과 크림을 유지 |

한 화면의 큰 면적은 목재·크림·자연색으로 제한하고, 고채도 강조색은 상호작용·상품·꽃처럼 작은 초점에만 쓴다. 임의의 무지개색 소품을 추가하지 않는다.

## 재질

- 목재·천·도기·석재는 중간~높은 거칠기, 낮은 금속성을 기본으로 한다.
- 플라스틱처럼 번쩍이는 넓은 하이라이트를 피한다.
- 채도는 캐릭터와 아이템 아이콘보다 한 단계 낮게 유지해 상호작용 대상이 묻히지 않게 한다.
- 발광은 등불·간판·피드백에만 제한하고 낮에는 과도하게 밝히지 않는다.
- 한 오브젝트 안의 재질 슬롯은 기능 구분에 필요한 수만 둔다.

## 형태 언어와 밀도

- 주요 실루엣은 둥근 모서리, 완만한 지붕, 두꺼운 목재 프레임, 짧고 안정적인 비율을 쓴다.
- 상점 가구는 상판·다리·수납·손잡이·작업면이 멀리서도 구분되어야 한다.
- 원시 큐브는 블록아웃에는 쓸 수 있지만 최종 카메라에서 큰 면적으로 노출하지 않는다.
- 권장 삼각형 밀도: 작은 소품 300~3,000, 중형 가구 1,000~8,000, 건물 5,000~30,000, 주연 캐릭터 15,000~45,000을 시작 범위로 삼는다. 숫자보다 실루엣과 실제 화면 크기를 우선한다.
- 반복 배경물은 LOD 또는 단순 변형을 준비하고, 화면에 거의 보이지 않는 미세 기하를 늘리지 않는다.

## 상점과 마을 분위기

상점은 주민 생활의 중심이며 가장 정돈되고 따뜻한 장소다. 상품 진열, 가격, 계산, 포장, 보관의 위치가 외형에서 읽혀야 한다. 마을은 완벽하게 대칭인 테마파크보다 주민이 실제로 쓰는 길, 상자, 화분, 벤치, 작업 흔적을 가진다. 장식은 기능과 이야기가 있을 때만 추가한다.

창고는 산업용 박스가 아니라 저장 기능이 즉시 읽히는 생활형 보관 공간이어야 한다. 작업대는 장식 테이블이 아니라 기존 제작·포장·진열 준비 루프를 연결하는 명확한 작업면이어야 한다.

## 조명 원칙

- 낮: 크림색 바닥과 자연색이 읽히는 부드러운 주광. 캐릭터 얼굴/실루엣을 검게 만들지 않는다.
- 저녁: 방향광을 따뜻하게 낮추고 상점 입구·간판·등불이 다음 행동을 안내한다.
- 밤: 전체를 검게 누르지 않는다. 상점은 가장 따뜻한 초점, 길은 이동 가능한 최소 밝기, 하늘/주변은 차가운 대비를 준다.
- 그림자는 접지와 깊이를 보여주되 플레이어·NPC의 눈/얼굴을 잃을 만큼 강하지 않게 한다.

## 카메라와 가림

플레이어, 상점 입구, 판매대가 첫 시선의 삼각형을 만든다. 큰 지붕·나무·간판이 캐릭터와 상호작용 지점을 장시간 가리면 위치·높이·투명/가림 정책을 조정한다. 카메라에 가까운 장식보다 핵심 동선의 가독성을 우선한다.

## UI

- 2560×1440 기준 본문은 한 번에 읽히는 크기와 명도 대비를 확보한다.
- 패널 가장자리 여백은 최소 16~24px 체감, 버튼 간격은 오입력을 막을 정도로 유지한다.
- 배경 투명도는 월드를 완전히 지우지 않되 텍스트 가독성을 보장한다.
- 같은 행동 계열은 색·모서리·타이포 계층을 통일한다.
- 월드 안내와 HUD가 같은 정보를 중복해 화면 중심을 가리지 않게 한다.

## 금지할 AI 슬롭

- 목적 없이 흩뿌린 상자·화분·도구·표지판
- 서로 다른 화풍·스케일·재질의 생성물을 한 장면에 혼합
- 읽을 수 없는 생성형 문자와 가짜 상표
- 기능이 없는 손잡이·문·도구, 접근할 수 없는 작업면
- 비슷한 소품의 무작위 회전·색상만으로 다양성을 가장하는 배치
- 손상된 메시, 뒤집힌 노멀, 떠 있는 피벗, 텍스처 늘어짐을 분위기로 포장
- 플레이어/NPC 정체성을 검토 없이 전면 교체
