# 발견 도감 (휴대폰 앱)

작성 2026-11-03 · 코드 권위: `World/DiscoveryLog.cs`(기록), `UI/CollectionPhoneUI.cs`(화면), `UI/SmartphoneUI`(홈 타일 "도감", `OpenCollectionApp`).

- 왜: 낚시·곤충·해변 줍기·파기로 늘어난 발견물을 '모으는' 동기(레퍼런스 생활 게임 공통의 도감 고리). 처음 손에 넣은 순간을 알림으로 축하하고, 아직 못 찾은 칸은 실루엣과 찾는 곳 한 줄 힌트로 다음 행동을 알려 준다.
- 대상 10종: 바다(참치·도미·옐로탱) · 곤충(나비) · 해변(가리비·소라·불가사리) · 땅속(점토·옛 동전·화석 조각).
- 기록: 가방(핫바·가방)을 0.5초마다 훑어 처음 보는 대상 id를 기록(아이템·재고는 건드리지 않음). 처음이면 알림 "새 발견! 이름 / 도감 n/10". 섬을 열 때 비우고, 이어하기는 `SaveData.discoveredItemIds`(v17 안 추가 필드)로 되돌린다. 불러온 직후 4초는 알림 없이 조용히 기록.
- 화면: 휴대폰 홈 두 번째 줄 "도감 · 발견한 것"(책 그림). 섹션 카드 4개, 발견 = 종류 색 받침 + 아이콘 + 이름, 미발견 = 회색 받침 + 실루엣 + "???", 위에 "발견 n / 10". 홈 아래 장식 선·문구는 자리를 내주려고 숨김.
- 검증: capture-ui-r5/r6 — 가방 채우기 뒤 발견 7/10, 알림 "새 발견! 참치 / 도감 7/10", 도감 화면 이름 겹침 수정(r6), 오류 0.
- 아침 소식(2026-11-03): 날이 바뀌면(불러오기 직후 4초 제외) 2초 뒤 "Day n 아침 / 해변 발견물 n개 · 파기 자국 m개가 새로 생겼어요" 알림 + 휴대폰 기록. night 플랜에서 `AdvanceToNextDayMorning` → Day 2 해변 9·파기 6·소식 1회(capture-night-r5).
- 완성 알림(2026-11-03): 섹션을 다 채우면 "도감 · 해변 완성! / 마지막 발견: … · 도감 n/10", 10종 모두면 "도감을 모두 채웠어요!". capture-ui-r7 completions=2(해변·땅속), 오류 0.
