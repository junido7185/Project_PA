## 이름 규칙 (2026-11-07 사용자 지시)
- 물고기·곤충·동식물은 **실제로 있는 종의 우리말 이름**을 쓴다. 모델 생김새와 맞는 종을 고른다(주황 날개 → 네발나비, 크림 날개·불빛 → 흰불나방, 주황 다섯 팔 → 별불가사리, 검은 털옷·주황 배 끝 → 호박벌 Bombus ignitus).
- 표시 이름은 `ItemDisplayName`에서 바꾸고 저장·검색 키(id·itemName)는 그대로 둔다.
- 도감 상세에 "실제로는" 한 줄: 확인된 사실만 짧게(박물관 설명처럼). 지어낸 습성은 쓰지 않는다.
- 2026-11-09 기념패 손님 반응: 가게에 도감 기념패를 두면 저녁 손님이 한 번 "도감 기념패네요! 많이 모으셨어요."(`DecorThemeSets.Singles`). 현금·생산 보상은 여전히 없음.
- 2026-11-09 쓰임 보강(연구 §8.1 "판매/요리/선물/소장 쓰임"): 상세 쓰임에 '선물'(특히 좋아하는 동행 — `DemoResident.LikedByLabel`, 예: "로건이 좋아해요 · 광부")과 '소장'(해변·땅속 발견물은 "가게 책상 위에 올려 둘 수 있어요")을 더함. 쓰임 칸은 12~15pt 자동 맞춤. ui 플랜 상세에 화석 조각 추가(선물·소장·넘침 검사) — r232 ui ok, 화면에서 네 줄이 칸 안에 들어감.
