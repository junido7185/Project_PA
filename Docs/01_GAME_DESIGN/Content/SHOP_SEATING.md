# 가게 의자 · 손님 쉬어 가기

작성 2026-11-03 · 코드 권위: `CustomerArrivalController`(TryTakeSeat/UpdateSeat/LeaveSeat), `World/NpcSitPose.cs`(앉은 자세), `DemoSettlementController.ShopChairs()`.

- 왜: 가게 안 의자는 숫자(손님 +1, 사치 +0.1, 가격 민감 −0.05)로만 효과가 있었고 화면에서는 아무 일도 없었다. 동행 대사("손님이 쉬어 가면서 더 온대요")와 맞게, 쇼핑을 마친 관광객이 빈 의자에 앉아 5.5초 쉬었다 나간다(동물의 숲·딩컴류 생활감).
- 규칙: 쇼핑(구매·거절)을 마친 관광객 → 상점 안 빈 의자 하나를 맡아 정면 0.6m까지 걸음(8초 제한) → 의자 정면을 보고 앉음(말풍선 "잠깐 쉬었다 갈게요.") → 일어나 기존 퇴장. 영업 마감·소환 때는 바로 일어나 퇴장. 의자는 한 사람만.
- 좌석: 개구리 의자(SimpleFurniture)는 `Sitpoint`(정면 = forward), 좌석 높이 = 의자 높이 42%. 소유 의자 모델은 `Seat` 윗면·`BackTop` 반대쪽.
- 자세: 허벅지 84° 들고 정강이 86° 내림, 골반을 좌석 위로 모델만 옮김(루트·NavMeshAgent는 의자 앞). 판매·저장 권위 없음.
- 함께 고친 것: 동행이 가게 안·가게 방문 중에는 도구를 넣어 둔다(Q-NL06 잔류 도구로 쇼핑). 손님 구매 반응 대사는 카메라 대화 구도를 쓰지 않는다(플레이어가 [E]로 건 대화만).
- 검증: decor 플랜(의자 2) seat-r2~r5: 관광객 8~9명 중 앉음 4~5명, 오류 0, 화면 확인(r5).

- 조개 장식(decor-shells)도 꾸밈 수에 들어간다(BEACHCOMBING.md). `ShopChairs()`는 의자만, `CountShopDecor()`는 의자 + 조개 장식.
