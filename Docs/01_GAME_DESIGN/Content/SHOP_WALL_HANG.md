# 가게 뒷벽 걸이 — 도감 기념패 (너굴 리스트 연구 H5 벽걸이)

2026-11-09 추가. 연구 H5(놓는 면 확장) 가운데 **벽걸이**를 넣었다. 배치 칸 시스템은 건드리지 않고, 가게 실내 뒷벽의 고정 자리 하나만 쓴다(책상과 창문 사이 빈 벽).

## 규칙
- 거는 물건: 도감 기념패(2051)만. 도감 섹션을 채우면 받는 보상이다. 바닥에 세워 둘 수도 있고 벽에 걸 수도 있다.
- 걸기: 기념패를 들고 뒷벽 자리 앞에서 [E]. 안내는 `[E] 벽에 걸기 · 도감 기념패 · 바닥에 두려면 벽에서 떨어져요`.
  - 기념패를 고르면 기존 배치 문법대로 바닥 미리보기가 열린다. 그래도 벽 자리 앞에서는 [E]가 미리보기를 취소하고 벽에 건다.
  - 벽에서 떨어지면 [E]는 그대로 바닥 배치 확정이다.
- 떼기: 빈손으로 뒷벽 자리 앞에서 [E] `벽에서 떼기 · 도감 기념패` → 가방으로. 가방이 가득 차면 떼지 않는다.
- 걸린 모습: 기념패 모델에서 받침·다리를 숨긴 판(크림 테두리·청록 판·금빛 별·리본)만 보인다. 판 가운데는 바닥 위 약 1.8m. 충돌은 없다.
- 손님: 걸려 있으면 저녁 손님이 "도감 기념패네요! 많이 모으셨어요."라고 알아본다(`DecorThemeSets.RemarksInShop`). 바닥에도 있으면 한 번만 말한다.

## 저장
- `SaveData.shopWallHang`(추가 필드, "" / "plaque"). 옛 저장은 비어 있어 빈 벽으로 열린다.
- 이어하기: `SaveManager`가 `ShopWallHang.Pending`에 넣고, 실내가 생기면 건다.

## 구현 메모
- `World/ShopWallHang.cs`: 운영 가게 실내의 `CozyDressing` 아래에 걸이 자리(트리거)와 걸린 모델을 둔다.
  - 기념패를 들었는데 비어 있을 때나, 걸려 있는데 빈손일 때만 [E] 대상이 된다.
- `PlayerInteraction`: `ShopWallSpot`을 먼저 해석한다(러그와 같은 이유 — 가게 배치물의 자식).
  - 배치 미리보기 중에도 벽 자리가 대상이면 안내와 [E]를 벽 걸기로 돌린다.
- 캡처: `-pa-capture-plan wallhang`. 빈 벽 → 기념패 들기·안내 → 걸기(배치가 남지 않음·판 높이·받침 숨김·손님 말 목록) → 빈손 떼기 → 다시 걸기 → 저장·이어하기.

## 검증
- r208 wallhang: 걸기 안내, 배치 남지 않음, 기념패 1→0→1, 받침 숨김, 손님 말 목록, 떼기, 이어하기 뒤 유지가 모두 확인됐다. 화면에서 창문 왼쪽 빈 벽에 기념패 판이 보였다. 높이 검사는 판이 아니라 모델 뿌리를 재고 있어 판 가운데 기준으로 고쳤다(r209).
