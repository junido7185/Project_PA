# 가게 책상 위 발견물 (너굴 리스트 연구 H5 탁상 위)

2026-11-09 추가. 연구 H5(놓는 면 확장)의 마지막 갈래인 **탁상 위 작은 물건**을 넣었다. 배치 칸 시스템은 건드리지 않고, 가게 실내 책상 위에 고정 자리 하나를 둔다(램프 오른쪽 뒤, 책은 왼쪽·머그는 오른쪽 앞).

## 규칙
- 올릴 수 있는 것: 도감 해변·땅속 섹션의 발견물(가리비·소라·별불가사리·해초·해변 유리·산호 조각·점토·옛 동전·화석 조각·토기 조각·수정 원석·호박 조각). 손에 쥘 만한 것들이다.
- 올리기: 발견물을 들고 책상 앞에서 [E] `책상에 올리기 · {이름}`. 가방에서 하나가 빠진다.
- 바꾸기: 다른 발견물을 들고 [E]를 누르면 바뀐다. 올려 두었던 것은 가방으로 돌아온다. 같은 것을 다시 올리려 하면 대상이 되지 않는다.
- 내리기: 빈손으로 [E] `책상에서 내리기 · {이름}` → 가방으로. 가방이 가득 차면 내리지 않는다.
- 모습: 아이템 모델의 가장 긴 변을 .3m로 맞춰 책상 윗면에 앉힌다. 충돌은 없다.
  - r210: 높이 기준으로 크기를 맞추자 납작한 불가사리가 1.9m가 됐다.
  - r211: .26m에서는 램프 갓에 반쯤 가렸다.
- 손님: 저녁 손님이 "책상 위 {이름}이/가 예뻐요!"라고 알아본다(`DecorThemeSets.RemarksInShop`, 조사 자동).
- 발견물은 배치 장식이 아니라서 바닥 배치 미리보기는 열리지 않는다. 그래도 벽 걸이처럼 `IPrecedesPlacement`로 표시해, 미리보기 중에도 책상 자리가 먼저 [E]를 받는다.

## 저장
- `SaveData.shopDeskItem`(추가 필드, 아이템 id, 0 = 빈 책상). 옛 저장은 0이다.
- 이어하기: `SaveManager`가 `ShopDeskShelf.Pending`에 넣고, 실내가 생기면 올린다.

## 구현 메모
- `World/ShopDeskShelf.cs`(`ShopDeskSpot`): 운영 가게 실내의 `CozyDressing` 아래에 둔다.
  - 받을 수 있는 발견물을 들었고 지금 것과 다를 때, 또는 올려져 있는데 빈손일 때만 [E] 대상이 된다.
- `PlayerInteraction`: `ShopDeskSpot`을 먼저 해석한다(가게 배치물의 자식이라서).
- 캡처: `-pa-capture-plan desk`. 빈 책상 → 불가사리 올리기(앉음·크기) → 화석 조각으로 바꾸기(불가사리 돌아옴) → 손님 말 목록 → 빈손 내리기 → 다시 올리기 → 저장·이어하기.

  - 개수: 불가사리 1→0→1, 화석 1→0→1.
  - 모습: 앉음 0.000, 크기 (.30,.02,.29).

  - 내리기와 이어하기 뒤 불가사리 유지를 확인했다.
  - 화면에서 램프 오른쪽 책상 위에 주황 불가사리와 화석 나선이 또렷하게 보였다.
