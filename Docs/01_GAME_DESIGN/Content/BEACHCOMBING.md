# 해변 줍기 (Beachcombing)

작성 2026-11-03 · 코드 권위: `Assets/Scripts/World/BeachFinds.cs`(배치), `Assets/Editor/PA_BeachFindsSetup.cs`(아이템·레시피·모델).

## 1. 왜 넣었나

- 레퍼런스 해안 장면(`References/Dinkum/images/03_coast_water.png`)과 섬 생활 장르의 공통 고리: **매일 아침 해변을 한 바퀴 돌면 뭔가 주울 게 있다.** 도구 없이 걷기만으로 얻는 첫 수입원이고, 바다 쪽으로 걸어갈 이유가 된다.
- 기존 해안은 낚시만 있었다. 발견물은 빈손 [E] 줍기(기존 `PickupItem` 맥락 줍기)를 그대로 써서 새 조작을 배우지 않는다.

## 2. 규칙

| 항목 | 값 |
|---|---|
| 놓이는 곳 | 물에서 2칸(4m) 이내, 걸을 수 있는 **모래** 칸(길·건물 제외) |
| 하루 개수 | 9개, 서로 7m 이상 떨어짐 |
| 날짜 | 새 날이 되면 남은 것은 사라지고 새로 놓인다(시드 = 날짜) |
| 줍기 | 빈손 + [E] → 핫바/가방. 가방이 차면 그대로 남는다 |
| 저장 | `SaveData.beachFindsDay`·`beachFindsCollected`(v17 안의 추가 필드). 같은 날 이어하기면 주운 자리는 다시 놓지 않고, 다른 날이면 새 날의 것을 놓는다. 과거 저장은 0/null → 그날 것을 모두 놓는다 |

## 3. 아이템

| id | 이름 | 확률 | 기본가 | 비고 |
|---|---|---|---|---|
| 2034 | 가리비 껍데기 | 55% | 8G | 원재료 |
| 2035 | 소라 껍데기 | 31% | 15G | 원재료 |
| 2036 | 불가사리 | 14% | 24G | 가장 드묾 |
| 2037 | 조개 목걸이 | — | 72G | 현장 작업대: 가리비 2 + 소라 1 (재료값 31G → 약 2.3배), 공예품 |

하루 기대 수입(전부 줍고 그대로 팔 때) ≈ 9 × (0.55·8 + 0.31·15 + 0.14·24) ≈ 112G. 목걸이로 엮으면 더 받는다.

2026-11-03 가격 조정: 처음 값(14/26/44G, 목걸이 112G, 하루 ≈195G)은 도구·미니게임 없이 줍기만 하는 불가사리(44G)가 낚은 물고기(Canon 확정 18G)보다 2배 이상 비싸 "낚시 대신 해변만 돌면 된다"가 됐다. 같은 하루 낚시(6마리 × 약 18G ≈ 108G)와 비슷한 규모로 낮추고, 가장 드문 불가사리만 물고기보다 조금 높게 두었다. 손님 1명이 1개를 사는 구조라 판매 수입은 공급이 아니라 진열·손님 수에 묶인다.

## 4. 모델·아이콘

- 외부 자산 없이 소유 로우폴리 메시(면마다 정점 분리 = 각진 음영): 부채꼴 골 가리비, 돌기 난 나선 소라 + 분홍 입구, 다섯 팔 불가사리, 끈 고리 목걸이.
- 아이콘은 공통 굽기(`PA_DemoIconBake`). 납작한 가리비·불가사리·목걸이는 아이콘에서만 카메라 쪽으로 48° 세운다.
- 월드 크기(높이 기준): 가리비 .1(폭 ≈ .43m), 소라 .28(길이 ≈ .42m), 불가사리 .05(폭 ≈ .5m). 기본 카메라에서 읽히게 실물보다 조금 크다.

## 5. 안내

- 동행 대사(`ResidentDialogueLines` after/after_none): 아침 모래밭 발견물, 목걸이 재료, 돈이 급할 때 해변.
