## 고리
바다에 세 번째 그림자 모양을 더한다. 정어리는 작은 무리, 고등어는 길쭉하고 휙 달림, 넙치는 넓적하고 오래 멈춘다. 새 상품은 만들지 않고, 넙치는 기존 생선구이(10)를 참치 대신 만든다.

## 찾기 — 넓적한 그림자
- 출현 비율(뽑기): 참치 .48 · 도미 .12 · 옐로탱 .15 · 정어리 .12 · 고등어 .07 · 넙치 .06. 참치 몫은 유지했다.
- 그림자: 같은 실루엣을 폭 ×1.35, 길이 ×.8로 만든 원반형. 내달리지 않고, 목표 지점을 고를 때 65% 확률로 3~6초 멈춘다(다른 종 30% · 1~2.6초).
- 낚시 방식은 기존과 같다. 새 미니게임·장비 조건·일일 상한 변화 없음.

## 모델·도감·대화
- 소유 로우폴리: 납작한 타원 원반, 윗면은 모래색 점무늬, 테두리에 짙은 지느러미 띠, 두 눈은 윗면 한쪽에 모여 있음.
- 바다 섹션 6번째 칸(도감 전체 21칸). 힌트 "넓적한 그림자 — 모래 바닥에 오래 멈춰 있어요".
- 벌목꾼 대사 한 줄.

## 검증
- `-pa-capture-plan flounder`(고등어 플랜과 같은 공용 단계 `FishShadow`·`FishCatch`·`FishKitchen`): 그림자 폭/길이·6초 동안 멈춘 시간, 실제 릴 미니게임 포획 → 도감, 조리대 '생선구이 · 넙치' 제작(참치 수 불변).
- build r146/r147: result=ok·예외 0. 그림자 scale (1.10,0.81,0.65), 6초 동안 멈춤 6.0s·이동 0m(물고기 쉬기 한 프레임 종료 문제 수정 뒤), 실제 릴로 넙치 → 도감 /21, 조리대 "생선구이 · 넙치" 생선구이 0→1·참치 불변.
