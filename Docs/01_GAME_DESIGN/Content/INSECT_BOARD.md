# 곤충 관찰 안내판 (2026-11-09, 연구 R09)

- 무엇: 판재에 이 섬의 곤충 아홉 가지 그림을 넣은 작은 산책로 안내판. 집이나 가게에 세우는 **꾸밈 전용** 배치물(2057, 쌓기 3, 값 없음 — 툴팁은 "꾸밈 전용 · 가게에 두는 물건이에요").
- 왜: 곤충 9종(네발나비·칠성무당벌레·고추잠자리·호박벌·방아깨비·장수풍뎅이·흰불나방·넓적사슴벌레·알락하늘소)을 모은 경험을 가게 꾸밈으로 잇는다. 레퍼런스 생활 게임 소품처럼 작은 지붕·나무 기둥·종이 그림판의 아기자기한 실루엣.
- 만들기: 현장 작업대 · 판재 2 + 나무 1(`Recipe_InsectBoard`). 연구 경계대로 **곤충을 쓰지 않는다**(잡은 곤충은 팔거나 표본으로 남긴다). 그림은 정적이며 발견에 따라 바뀌지 않는다(발견별 자동 갱신은 별도 후보).
- 모양(소유 로우폴리): 진갈색 기둥 둘 + 나무 판 + 크림 종이 + 초록 제목 띠 + 작은 박공 지붕. 그림은 앞면(-Z) 3줄×3칸: 나비(주황 날개)·무당벌레(빨강·검은 점)·잠자리(빨간 가는 배·연한 날개) / 호박벌(검정·주황 꼬리·흰 날개)·방아깨비(갈색 긴 몸·뒷다리)·장수풍뎅이(진갈색·뿔) / 흰불나방(크림 삼각 날개)·넓적사슴벌레(검은 몸·큰 턱)·알락하늘소(검은 몸·흰 점·긴 더듬이). (2026-11-09 곤충 9종에 맞춰 7→9)
- 배치: 키 `decor-insectboard`, 1칸, 생활·작업·가게 바닥, 옮기기 가능. 배치 높이 .95m, 상자 충돌체 .8×.95×.3. `PA_DemoStructureSetup`가 카탈로그를 다시 쓸 때 `ExistingEntries()`로 보존.
- 손님 반응(2026-11-09): 세트가 아니어도 가게에 놓여 있으면 저녁 영업에 들어온 손님이 한 번 "곤충 안내판이네요! 방아깨비도 있어요." 말풍선(`DecorThemeSets.Singles` → `DecorSetAppreciation`, 손님마다 영업 한 번 한 줄). 툴팁에 "가게에 두면 손님이 알아봐요".
- 손님 효과·생산 버프 없음(광물 받침·모자이크와 같음). 가게 꾸밈 수(`CountShopDecor` — 손님 쉼터용 의자·조개 장식만 셈)에는 들어가지 않는다.
