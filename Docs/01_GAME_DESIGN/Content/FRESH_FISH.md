# 강·하구 물고기 — 송어·장어 (아이템 생태 연구 F12·F09)

2026-11-09 추가.

## 전제 정정
앞선 Handoff에는 "섬에 하구·연못·강이 없다"고 적었는데, 이것은 확인이 부족했던 판단이다. 실제 생성 섬(`WorldIslandGenerator.CarvePondAndRiver`, seed 9009, 256×256)에는 다음이 이미 있다.
- 연못 9칸(3×3)
- 강 80칸(연못 동쪽에서 바다까지 한 칸 폭)
- 하구 한 곳(강 칸이 바다 칸과 맞닿는 곳, 월드 (474,0,278))

freshwater 탐사 플랜(r214)에서 실제 격자의 물 칸이 연못 9/9·강 80/80이었고, 화면도 확인했다.
- **하구:** 모래 해변을 지나 바다와 만나는 모습이 자연스럽다.
- **강:** 초원 구간은 한 칸 폭의 깊은 도랑이고, 하구 쪽 모래밭 구간은 얕아서 잘 보인다.
- **연못:** 고지대 바위 지형에 파인 구덩이라 물이 일부만 보인다.

## 규칙
- **송어(3008, 25G):** 실제 종 송어(Oncorhynchus masou, 강에 남은 것은 산천어).
  - 구역: 강·연못 안쪽(하구 12m 제외), 06–18시.
  - 그림자: 날렵한 중간 크기(길이 .75–.9, 폭 ×.6).
  - 릴 난이도 .4.
  - 요리: 조리대에서 송어 1 + 나무 2로 훈제 생선(2033)을 만든다(`Recipe_SmokedTrout`, 새 산출물 없음).
- **장어(3009, 35G):** 실제 종 뱀장어(Anguilla japonica).
  - 구역: 하구 12m 안, 14–24시.
  - 그림자: 몸 마디 5개를 이어 머리에서 꼬리로 갈수록 크게, 위상이 늦게 좌우로 굽이친다. 연구 문구 "공통 몸 비율 조정만으로 완료 처리하지 않음"에 따른 것이다. 내달리지 않는다.
  - 릴 난이도 .5.
  - 요리: 조리대에서 장어 1로 생선구이(10)를 만든다(`Recipe_GrilledEel`).
- **숭어:** 항구 18m 안에 더해 하구에도 나온다(연구 F07 "항구/하구"). 하구 몫은 .2.
- **바다 물고기(참치·도미·옐로탱·정어리·고등어·넙치·복어):** 강·연못 안쪽(하구 제외)에는 나오지도, 헤엄쳐 들어가지도 않는다(`InZone` + 기존 구역 leash).
  - 연구 F12 "바다 추첨표에 이름만 넣지 않음"에 맞춰, 강 안쪽은 송어만 뽑는다.
- **출현 시간:** 그림자 생성 단계에서 `FishingSpot.ActiveNow`로 거른다.
- **도감:** 섹션 이름을 "바다"에서 "물고기"로 바꿨다(10칸, 4열). 힌트는 "낚싯대로 바다·강·하구에서"이고, 전체는 33칸이다.
  - 탭 폭을 이름 길이에 비례해 나눴다(r216).
  - 저장은 id만 쓰므로 섹션 이름 변경의 영향이 없다.
- 대사: 벌목꾼(강 송어)·농부(하구 장어).
