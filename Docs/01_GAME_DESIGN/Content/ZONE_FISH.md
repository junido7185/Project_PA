# 자리 물고기: 숭어·복어 (2026-11-09, 연구 F07·F08)

- 왜: 연구 후속 물고기 중 섬에 이미 있는 자리를 쓸 수 있는 두 종. 같은 낚시라도 **어디서 던지느냐**에 따라 만나는 물고기가 달라진다(찾는 법 확장).
- 숭어(3006, 20G, 실제 종 Mugil cephalus): **항구 18m 안** 물가에서만. 고등어보다 조금 굵은 길쭉한 은빛 그림자(폭 ×.7, 길이 .95~1.1). 릴 .38. 기존 생선구이(10)의 대체 재료(조리대 숭어1, `Recipe_GrilledMullet` — 새 산출물 없음).
- 복어(3007, 30G, 실제 종 졸복류 Takifugu): **물가 바위 4m 안**에서만. 작고 동글동글한 그림자(폭 ×1.15, 길이 .5~.6), 내달리지 않고 느릿느릿. 릴 .18(쉬움). 독이 있어 **요리에 넣지 않음**(연구 "범용 요리·필수 납품 제외") — 팔거나 도감.
- 출현: 기본 비율은 0이고 그 구역 그림자·찌에만 몫(숭어 .16, 복어 .14)이 더해진다(`FishingSpot.PickSpecies(at)`·`InZone`). QA 출현 편향도 구역 안에서만. 기존 6종 비율은 그대로.
- 도감 바다 8칸·전체 31, 힌트 "항구 앞 물가 — 길쭉한 은빛 그림자" / "물가 바위 곁 — 동글동글 느린 그림자", 실제로는 "항구와 강어귀에 많이 살아요. 물 위로 펄쩍 뛰어오르기도 해요." / "몸에 독이 있어 함부로 먹으면 안 돼요. 놀라면 몸을 동그랗게 부풀려요." 농부·광부 대사.
- (정정 2026-11-09) 생성 섬에는 강·연못·하구가 이미 있었다 — 송어(강)·장어(하구)는 `FRESH_FISH.md`로 구현, 숭어는 하구에도 나온다. 붕어·잉어(연못)는 연못이 고지대 구덩이 3×3이라 보류.
- 코드: `Editor/PA_ZoneFishSetup.cs`, `FishingSpot`(종 6·7, `HarborZone`), `ShoreFishSchool`(크기·모양·움직임), `FirstDayLandedFish`(뭍 길이), 캡처 `-pa-capture-plan mullet|puffer`(구역 밖 0 → 구역에서 그림자 → 실제 낚시·릴 → 도감 → 숭어 생선구이).
