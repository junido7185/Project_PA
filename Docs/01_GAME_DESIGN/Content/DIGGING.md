# 삽 · 파기 자국 (Digging)

작성 2026-11-03 · 코드 권위: `Assets/Scripts/World/DigSpots.cs`(배치·파기), `Assets/Editor/PA_DigSetup.cs`(아이템·레시피·모델), `PlayerLocomotionAnimator.ShovelDig`(자세).

## 1. 왜 넣었나

- 레퍼런스 09(`References/Dinkum/images/09_shovel_target.png`, 삽을 든 캐릭터와 지면 대상 표시)와 섬 생활 장르의 공통 고리: **땅을 파면 뭔가 나온다.** 도끼·곡괭이·채·낚싯대 다음 다섯 번째 도구.
- 풀밭을 걸어 다닐 이유를 만든다(해변 줍기 = 물가, 파기 = 내륙 풀밭). 점토는 화로 가공으로 이어진다.

## 2. 규칙

| 항목 | 값 |
|---|---|
| 자국 위치 | 상점(없으면 첫 위치) 70m 안, 걸을 수 있는 풀·흙 칸. 길·모래·물가 2칸·막힌 칸 옆·상점 8m 안 제외 |
| 하루 개수 | 6개, 서로 9m 이상. 새 날에 새로 놓인다(시드 = 날짜) |
| 보이는 모양 | 흙 둔덕 + X자 갈라짐 + 흙덩이. 몇 초마다 한 번 들썩인다(멀리서도 '뭔가 있다') |
| 파기 | 삽을 들고 [E] → 삽날이 닿는 순간(0.28초) 파임 → 보상이 바닥에 떨어짐 → 빈손 [E]로 줍기. 삽 내구도 1 |
| 삽 없이 [E] | "흙이 들썩이는 자리는 삽으로 팔 수 있어요. 삽은 현장 작업대에서 만들어요." |
| 저장 | `SaveData.digSpotsDay`·`digSpotsDug`(v17 안 추가 필드). 같은 날 이어하기면 판 자리는 다시 놓지 않는다 |
| 입력 | 기존 PlayerInteraction의 '대상 있는 [E]' 경로(Interact → PlayAction). 새 입력·예약 파일 수정 없음 |

하루 기대 수입(6곳 전부 + 그대로 판매) ≈ 6 × (0.55·18 + 0.27·36 + 0.18·64) ≈ 187G. 삽 제작(나무 2 + 광석 1)·이동·내구도(20회)를 치르는 만큼 해변 줍기(≈112G)보다 조금 높다.

2026-11-03 가격 조정: 처음 값(동전 48G·화석 85G, 하루 ≈230G)은 화석 하나가 공예품 목걸이·구운 항아리보다 비싸 가공 동기를 깎았다. 화석은 100G 희귀 경계 아래 64G(= 구운 토기 항아리)로, 동전은 36G로 낮췄다.

## 4. 표현

- 삽 자세 `ShovelDig`: 날을 앞 아래로 겨눔(0.12s) → 땅에 찔러 넣음(접촉 0.28s) → 흙을 떠 올림(0.44s) → 들기 복귀(0.62s). 오른손은 손잡이 끝, 왼손은 자루 중간(기존 무거운 도구 받침 손).
- 모델: 소유 로우폴리(돌림판 메시 + 8각 부품). 삽(나무 자루·D 손잡이·철 날), 둥근 점토, 네모 구멍 엽전, 나선 화석, 배 불룩한 항아리.
- 아이콘: 납작한 동전·화석은 아이콘에서만 카메라 쪽으로 세운다.
- 대상 표식: 삽을 들면 화면 안 12m의 파지 않은 자국 위에 삽 아이콘 원판(`HarvestTargetMarkers`, 도끼·곡괭이와 같은 표식)이 뜬다(레퍼런스 09 지면 대상 표시). capture-dig-r5 확인.

## 5. 안내

- 동행 대사(after): 광부 = 자국 위치와 삽 재료, 벌목꾼 = 화석·X자 갈라짐, 농부 = 점토 → 항아리.
