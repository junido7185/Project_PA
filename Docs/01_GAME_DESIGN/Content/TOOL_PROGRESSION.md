# 도구 단계·재료·채집·가공 설계 (데모 첫날 경로)

작성 2026-11-02 · 근거 요청: 사용자 "개선 곡괭이 말고 다른 게임들처럼 구리·철 곡괭이 같은 도구 업그레이드 설계 및 재료 설계, 재료 채집 설계, 가공 설계".
상위 문서: [CRAFTING_STATIONS.md](CRAFTING_STATIONS.md)(작업대·레시피), Opening Demo Canon v2 §8 Utility. 새 저장 스키마 없음(아이템은 id로 저장, 바위 종류는 월드 생성에서 결정).

## 1. 한 줄 요약

**바위를 캐서 광석 → 화로에서 주괴 → 주괴로 다음 단계 도구 → 더 단단한 바위·더 빠른 벌목.** 기본 → 구리 → 철, 3단계. 구리 단계는 누구나, 철 단계는 해당 전문 분야(광업·임업)를 고른 개척자만 만든다.

## 2. 도구 단계

| 단계 | 곡괭이 | 도끼 | 힘 | 만드는 곳 · 재료 | 조건 |
|---|---|---|---|---|---|
| 기본 | 곡괭이(2002) | 도끼(2001) | 1 | 보급 상자 | — |
| 구리 | 구리 곡괭이(2022, 옛 '개선 곡괭이') | 구리 도끼(2030) | 2 | 화로 · 이전 도구 + 구리 주괴 2 + 나무 1 | 없음 |
| 철 | 철 곡괭이(2031) | 철 도끼(2026) | 3 | 화로 · 구리 도구 + 철 주괴 2 + 판재 1 | 광업(곡괭이) · 임업(도끼) 전문 |

- **힘**은 한 번 휘두를 때 깎는 양이다. 바위: `힘 − 단단함 + 1`(최소 1), 나무: `힘`. 바위·나무는 2~4번을 버틴다.
- 힘이 바위 단단함보다 낮으면 튕겨 나오고 "구리 곡괭이 이상이 필요해요"라고 알려 준다(내구도 안 닳음).
- 이전 도구를 재료로 넣는다(손에 익은 도구를 고쳐 쓰는 감각, 가방 칸 정리). 내구도: 기본 5/30, 구리 곡괭이 25 · 구리 도끼 12, 철 곡괭이 40 · 철 도끼 25.
- 광부 동행에게 구리 곡괭이를 건네면 기존처럼 일 속도 ×1.5(`DemoToolUpgrade`).

## 3. 재료

| 재료 | id | 분류 | 값 | 얻는 곳 |
|---|---|---|---|---|
| 구리 광석(옛 '광석') | 4 | 원재료 | 15G | 일반 바위 ×3 |
| 철 광석 | 2028 | 원재료 | 24G | 철 광맥 바위 ×3 (구리 곡괭이 이상) |
| 구리 주괴 | 2029 | 가공품 | 38G | 화로: 구리 광석 2 + 나무 1 |
| 철 주괴 | 6 | 가공품 | 62G | 화로: 철 광석 2 + 나무 1 (기존 '광석 2'에서 변경) |

- 나무는 화로의 땔감이다. 임업(나무)이 제련의 병목이 되어 동행·분야 선택이 서로 이어진다.
- 키트(조리대 판재3+광석2, 화로 판재2+광석4)의 광석은 구리 광석이다.

## 4. 채집(어디서 얻나)

| 바위 | 위치 | 단단함 | 결과 | 보이는 표시 |
|---|---|---|---|---|
| 일반 바위 | 해안·초원·숲 | 1 | 구리 광석 ×3 | 바위 겉에 주황빛 구리 알갱이 |
| 철 광맥 바위 | 고지대·높은 단 우선, 전체 바위의 1/5(최소 3) | 2 | 철 광석 ×3 | 더 어두운 바위 + 붉은 녹빛 알갱이 |

- 첫 바퀴: 기본 곡괭이로 일반 바위 → 구리 주괴 → 구리 곡괭이 → 고지대 철 광맥. 철 광맥을 기본 곡괭이로 치면 튕겨 나오면서 다음 목표가 보인다.
- 바위는 다시 자라지 않는다(기존 직접 자원 규칙). 데모 하루 분량으로 충분한지 실제 플레이로 확인한다.

## 5. 가공(화로)

화로 키트(작업대: 판재 2 + 광석 4)를 정착지에 놓으면 제련과 금속 도구를 맡는다.
제련 2종(구리 주괴·철 주괴) → 도구 4종(구리 곡괭이·구리 도끼·철 곡괭이·철 도끼) + 튼튼한 낚싯대(철 주괴 1 + 판재 1) + 철제 도구(등급 1 잠금).

## 6. 구현 위치

- 힘·전문 조건 표: `ToolPower`(코드 데이터). 제작 잠금 `DemoPlaceableCatalog.RecipeUnlocked`가 함께 본다.
- 바위 단단함·보상: `MiningSpot.ConfigureDirectWorld(..., hardness)`, 바위 종류 결정·표시: `WorldGameplayAdapterService`(FirstDay 직접 자원).
- 나무: `Gatherable` 직접 자원 타격량 = 도끼 힘.
- 아이템·레시피 생성/갱신: `PA_ToolProgressionSetup.Apply`(멱등, id·이름 충돌 검사, Resources/DemoStructure).
- 검증: `-pa-capture-plan tools`(격리 저장 사본) — 기본 곡괭이로 철 광맥 튕김 → 구리 주괴·구리 곡괭이 제작 → 철 광맥 채집 → 철 주괴.

## 7. 검증(2026-11-02, `capture-tools-r2`)

바위 70개 중 철 광맥 14개. 기본 곡괭이로 철 광맥 → 튕김(남은 3회 그대로, "구리 곡괭이 이상이 필요해요"). 화로: 구리 주괴 4 → 구리 곡괭이·구리 도끼. 구리 곡괭이로 철 광맥 3번 → 철 광석 3 줍기 → 철 주괴 1. 구리 곡괭이로 일반 바위 2번, 구리 도끼로 나무 2번. 철 곡괭이는 철 주괴 2가 필요해 재료 부족 표시. 오류·예외 0.
