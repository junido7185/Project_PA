## 찾기 — 무리
- 출현을 뽑을 때 정어리가 나오면 우두머리 + 따라붙는 2마리(우두머리 뒤 좌우 .4~.55m)로 나타난다. 동료는 우두머리 몸 방향 기준 자리를 따라가고, 우두머리가 잡히거나 사라지면 따로 헤엄친다. 놓을 자리가 물이 아니면 그만큼 적게.
- 출현 비율(뽑기): 참치 .48 · 도미 .17 · 옐로탱 .20 · 정어리 .15. 무리 때문에 화면 속 개체 비율은 정어리 약 35%, 참치 약 37%. 낮 활동·조리 목표가 참치(`Items/Item_Fish`)를 직접 세므로 참치 몫은 거의 그대로 두고 도미·옐로탱에서 덜었다. (2026-11-04 고등어 추가 뒤: 참치 .48 · 도미 .13 · 옐로탱 .16 · 정어리 .13 · 고등어 .10 — `MACKEREL.md`)
- 낚시는 기존과 같다(그림자 선택 → 입질 → 릴 → 뭍에서 잡기 → 가방). 새 미니게임·새 장비 조건 없음. 일일 6마리 상한도 그대로.
