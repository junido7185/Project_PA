## 고리
바다에 그림자 모양이 다른 물고기를 하나 더 두어 '어떤 그림자를 노릴지'를 고르게 한다. 새 상품은 만들지 않는다. 고등어는 기존 훈제 생선(2033)의 재료를 참치 대신 채운다. 참치는 구이·꼬치·해초말이·낮 목표에 그대로 남는다.

## 찾기 — 길쭉한 그림자
- 출현 비율(뽑기): 참치 .48 · 도미 .13 · 옐로탱 .16 · 정어리 .13 · 고등어 .10. 낮 활동·조리 목표가 참치를 직접 세므로 참치 몫은 그대로 두고 도미·옐로탱·정어리에서 덜었다.
- 그림자: 같은 실루엣을 폭만 .62배로 줄여 길쭉하게. 처음 달리기는 1.5~4초 안에, 그다음은 3~6초마다 짧게 내달렸다가 멈춘다(다른 종은 8~18초).
- 낚시 방식은 기존과 같다(그림자 → 입질 → 릴 → 뭍에서 잡기 → 가방). 새 미니게임·장비 조건·일일 상한 변화 없음.

## 도감·대화
- 바다 섹션 5번째 칸(도감 전체 20칸). 힌트 "길쭉한 그림자 — 휙 달렸다가 쉬어요".
- 농부 대사 한 줄: 고등어 그림자 알아보기와 훈제 대체.
