# 동행 선물

작성 2026-11-03 · 코드 권위: `World/DemoResident.cs`(CanGift/Likes/Gift), `NpcDialogue.SayToPlayer`, 친밀도 `FriendshipService`(기존, SaveData v4 friendshipData).

- 왜: 해변·파기·가공으로 늘어난 물건이 판매 말고도 동행 관계(대화창 이름표 하트)로 이어지게 한다. 레퍼런스 생활 게임의 공통 고리(주민에게 선물 → 친밀도).
- 규칙: 도구가 아니고 판매 가능한(기본가 > 0, 설비 키트 아님) 물건을 들고 동행에게 [E] → 1개를 주고 친밀도 +3(보통) / +5(공예품) / +8(좋아하는 물건). 하루 한 번(같은 날 두 번째는 정중히 사양, 물건 유지). 도구 전달(작업 속도)은 기존 규칙 그대로 우선.
- 좋아하는 물건: 광부 = 옛 동전·화석 조각·철 주괴·구리 주괴, 벌목꾼 = 판재·나비 액자·조개 목걸이·토기 항아리, 농부 = 생선구이·모둠 꼬치·훈제 생선·작물·빵.
- 표현: 프롬프트 "로건에게 화석 조각 선물하기"(오늘 준 뒤 "오늘 선물 완료"), 대답은 [E] 대화와 같은 대화창·대화 구도·하트 갱신. 동행 다음 날 대사로 좋아하는 물건 힌트.
- 저장: 하루 한 번 기록은 FriendshipService 날짜 기록 키 `gift:<friendshipId>`(기존 friendshipData에 함께 저장, 새 필드 없음).
- 검증: capture-gift-r1 — 광부 화석 0→8점(하트 첫 칸 80%), 벌목꾼 가리비 0→3점, 같은 날 두 번째 사양(가리비 1→1), 오류 0. capture-gift-r2(저장 키 방식) 동일 결과.
- 친밀도 답례(2026-11-03): 하트 단계가 오르는 순간 동행이 역할 물건을 건넨다 — 광부 1단계 구리 주괴 ×2 / 2단계~ 철 주괴 ×1, 벌목꾼 판재 ×3 / 의자 ×1, 농부 생선구이 ×2 / 모둠 생선 꼬치 ×1. 가방이 차면 발밑에 떨어뜨린다. 알림 "친밀도 n단계! / 물건 ×n 받았어요". `FriendshipService.OnLevelChanged`는 불러오기에서 울리지 않아 중복 지급이 없다. 선물로 오른 경우 선물 대답 뒤에 답례 말을 잇는다.
- 검증(답례): capture-gift-r3 — 광부 대화 +2 → 화석 +8 = 10점 → 1단계, 구리 주괴 0→2, 하트 첫 칸 가득, 오류 0.
- 감정 별(2026-11-04, 레퍼런스 04): 선물 순간 주민 머리 둘레로 별이 엇갈려 피어올라 1.5초에 걸쳐 사라진다 — 평범한 선물 금빛 3, 좋아하는 선물 분홍·금빛 6, 친밀도 단계 섞어 8(`World/NpcEmote.cs`, 발견물 반짝임과 같은 별 그림). 표시 전용. capture-gift-r133 `gift_liked_1b_emote_ui.png`, result=ok·예외 0. 대화창의 "다음 ▼" 표시는 대화가 자동으로 닫히는 구조라 넣지 않음(누를 입력이 없는데 누르라는 신호가 됨).
