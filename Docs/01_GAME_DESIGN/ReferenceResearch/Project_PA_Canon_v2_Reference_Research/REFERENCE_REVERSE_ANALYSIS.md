## 원작에서 공통으로 유도한 원리 I

행동이 어떤 대상에 적용됐는지 읽혀야 한다. 시도·유효 작업·획득·판매는 다른 사실이다. 결과는 다음 판단에 사용할 정보가 되어야 한다. 공간의 자유는 놓은 뒤의 이동/생활/고객 흐름을 예측할 수 있어야 성립한다. 낮밤은 같은 물건·장소·인물·사건을 이어야 하나의 하루가 된다.

이 원리들은 원작의 내부 코드나 제작자의 확정 의도라는 주장이 아니다. 각 문서에 성립 조건과 반증 가능한 P.A. 검수가 있다. 정답 수치·아트·레이아웃을 가져오는 방식 대신 [개발 지식](CANON_V2_DEVELOPMENT_KNOWLEDGE.md)으로 전환한다.

## 근거를 재확인하는 순서

[SCENE_LEDGER](03_evidence/SCENE_LEDGER.md)의 장면 ID → 출처 clip과 **그 clip 기준** 시각 → 해당 분석 문서 순서로 읽는다. 표본 구간을 원작 입력 지연으로 쓰지 않는다. U가 중요한 구현 수치라면 [OPEN_QUESTIONS](03_evidence/OPEN_QUESTIONS.md)의 좁은 관찰 단위를 수행한 뒤 결정한다.
