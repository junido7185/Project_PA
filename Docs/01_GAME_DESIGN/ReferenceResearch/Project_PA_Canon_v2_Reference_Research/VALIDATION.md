# 연구본 검증 기록

검증일: 2026-10-11. 검증 대상은 Markdown 연구 자료이며 Unity 구현의 실행 검증이 아니다.

## 확인한 것

- Canon·IDENTITY 보존본의 UTF-8 bytes를 Git blob SHA-1 방식으로 계산했다. Canon `b4d5260cd96940a4f4b90a3e5665970564c58c8e`, IDENTITY `203f6b2bb8721836a4c4b5c19f2bbdc96a5b2627`와 각각 정확히 일치한다.
- 모듈 간 상대 링크 대상이 실제 존재하는지, 코드 fence가 닫혔는지, 문서 제목이 있는지 확인했다.
- 사용한 PA/DK/AC/ML/ML2/DV 출처 ID가 SOURCE_LEDGER에 등록되어 있는지 확인했다. 파일명 중복이 없다.
- 현재 NpcController의 동기 평가/구매를 읽고 가격 drift를 현재 실행 버그로 단정하는 해석을 제거했다. 미래 지연 연출과 재진입 검수로 범위를 좁혔다.
- 파일 FPS·클립 시각·Canon 목표·현재 구현 설정·미확인 원작 수치를 구분했다. 무음 영상으로 원작 음향을 관찰했다고 쓰지 않았다.
- 원작 미디어/추출 프레임/자산과 helper·임시 분석 파일을 배포 묶음에서 제외했다.

## 이번 검증으로 보증하지 않는 것

Unity 컴파일·Play·standalone 실행·모든 호출 경로·현재 원작 버전의 전체 조작·원작 음향·장시간 무편집 영상은 새로 검증하지 않았다. 저장소의 PASS는 원 기록의 날짜/fixture/경로 한계 안에서만 인용했다. Q 시나리오와 W 작업은 구현 후 수행할 가설/검수이며 이번 연구의 PASS가 아니다.

## 후속 갱신의 기준

GitHub HEAD가 바뀌면 현재 상태/코드 경계를 다시 대조한다. 새로운 원작 영상은 버전·플랫폼·시각·음향/편집 제한을 새 출처 ID로 기록한다. 영향을 받는 가설과 검수 시나리오를 함께 고친다. Canon의 수정은 연구 문서를 고치는 것으로 대신하지 않는다.
