재관찰할 때는 ‘더 길고 선명한 원본 영상에서 UI 전체·입력·음향·연속 실패가 보이는가’를 먼저 확인한다. 공식 홍보 영상이라는 이유만으로 숨겨진 시스템의 사실성이 올라가지 않는다.
