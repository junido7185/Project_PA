# Project P.A. 경험 구조와 연구 우선순위

연구 기준일: 2026-10-11. 기준 브랜치: `milestone/gameplay-beta-85`. 조회한 HEAD: `b121140ae6f5ca0f92078db5c2f75512dc8fc95a`.

이 자료의 권위 순서는 **Canon v2의 데모 계약 → IDENTITY의 정체성 → 현재 구현·검증 기록 → 레퍼런스 → 이 연구의 제안**이다. 레퍼런스가 더 세련되어 보여도 Canon을 대체하지 않는다. 원문은 [Canon 보존본](CANON_V2_snapshot.md), [정체성 보존본](IDENTITY_snapshot.md)에서 읽는다.

## 경험의 중심

플레이어는 주민이면서 가게 주인이다. 낮에 직접 몸으로 이해한 물건을 밤에 자신의 판단으로 판매한다. 따라서 성공은 채집·배치·판매 기능의 개수보다 **같은 물건과 같은 장소에 대한 플레이어의 이해가 다음 행동으로 이어지는가**에 달려 있다. 이 문장은 설계 추론이며 Canon §0·§21과 IDENTITY §1–3에 근거한다.

| 단계 | 반드시 일어나는 경험 | 플레이어가 다음 단계로 가져가는 지식 | 주요 연구 |
|---|---|---|---|
| 본사 교육 | 이동·점프 → 나무 흔들기 → 사과 떨어짐 → E 줍기 → 핫바·손 → 진열·가격 → 구매/거절 | E는 문맥 행동, 선택과 손 표현은 일치, 상품과 가격은 고객 반응을 만든다 | ACT-01, COM-01 |
| 동행·항해 | 후보 3명 중 정확히 2명 → 짧은 픽셀 항해 → 3D 항구 조작 | 선택한 인물이 나와 함께 도착했다 | DAY-01, PRE-01 |
| 공급·채집 | 실제 가방 권위로 보급 → 직접 목재·돌 확보 | 재료의 위치·도구·성공·획득 차이를 안다 | ACT-01, WORLD-01 |
| 정착 | Shop/Base + 일반 텐트 2개 → 무주택 동행 자동 배정 | 내 배치가 생활과 상점의 공간을 만든다 | PLC-01, DAY-01 |
| 성장 | License Point → Root 첫 선택, 다음 노드 미리보기 | 더 좋은 도구를 내가 쓰거나 NPC에게 줄 수 있다 | DAY-01 |
| 해질녘 | 핵심 정착 이후 부드러운 시간 전환 → 상품 준비 | 낮의 물건이 밤의 상품이 된다 | DAY-01, COM-01 |
| 영업 | 3개 가판대 중 1개 이상 진열 → 가격 → OPEN → 실제 판매 → CLOSE | 가격과 손님의 판단을 보고 다음 결정을 한다 | COM-01 |
| 보고서 | 영업 후 평가와 실제 사건에 연결된 짧은 댓글 | 내가 한 일이 기록되고 다음 가능성을 보인다 | PRE-01 |

전체 Must Path는 Canon §21이다. 낚시·벌레·추가 탐험·추가 제작·NPC 도구 지급은 선택 활동이다. 선택 활동을 모두 마쳐야 해가 지거나 보고서를 볼 수 있게 만들면 데모 계약을 위반한다.

|---|---|---|---|
| P0 | 행동 → 성공 → 획득 → 손/가방 | 기능은 돌아가도 내가 무엇을 했는지 읽히지 않는다 | 한 번의 E, 잘못된 도구, 허공, 가득 찬 가방, 취소 |

| P2 | 항해·보고서 | 도입과 끝이 기능 메뉴처럼 느껴진다 | 제한된 쇼트의 의미, 사건에 대한 마감 피드백 |

## 결합 구조: 기능을 붙이는 대신 이해를 전달한다

1. **채집 → 재고:** 획득 연출이 보여준 물건과 가방의 물건이 같아야 한다. 가방 실패는 획득 성공처럼 연출하지 않는다.
2. **재고 → 진열:** 선택·들고 있음·수량·품질이 가판대로 넘어간다. 다른 가방 슬롯에서 임의로 상품을 골라주면 공통 조작 문법이 깨진다.
3. **배치 → 영업:** 자유는 손님이 접근하고 계산할 수 있는 공간 안에서 성립한다. 실패 이유를 문·동선·영역 단위로 읽게 해야 한다.
4. **가격 → 학습:** 고객의 반응이 어느 상품·어느 가격·어느 판단에 해당하는지 알 수 있어야 가격을 수정할 이유가 생긴다.
5. **정착 → 위임:** 직접 노동을 없애는 보상보다, 이미 이해한 노동을 더 잘하거나 일부 맡기는 선택을 보여준다.
6. **낮 → 밤 → 보고서:** 물건과 사건의 기록을 이어 붙인다. 보고서가 낮의 행동을 별도 점수 과제로 바꾸지 않게 한다.

## 가져오지 않을 것

ACNH의 현실 시간, Miles 과제 목록, 과일 힘/바위 파괴 규칙을 데모에 추가하지 않는다. Dinkum의 생존·전투·농장·광산 확장을 도입하지 않는다. Moonlighter의 던전·절도·가격 정답 데이터베이스나 속편의 상점 빌드 체계를 추가하지 않는다. Dave의 잠수 전투·산소·식당 서비스 미니게임을 추가하지 않는다. 이 제외는 원작의 가치 판단이 아니라 Canon §24에 따른 범위 제한이다.

IDENTITY의 ‘판 물건이 마을을 바꾼다’는 장기 방향이다. 데모의 기존 판매 기록을 이후 확장 가능한 사실로 보존할 수 있지만, 본 연구는 새 주민 소비·마을 변화 시스템을 데모 필수 기능으로 지정하지 않는다.

## 현재 구현에 대한 판정 경계

2026-10-06까지의 저장소 기록은 다수의 기능 검사 PASS를 보고하지만 자연 NEW GAME 연속 완주·동일 standalone 후보·최종 사람 체감 검증을 별도로 남긴다. 일부 검사는 fixture로 접근/재고/시간을 준비했다. 이 연구는 해당 기록과 10개 코드 파일을 읽었으며 Unity를 실행하지 않았다. 과거 PASS를 현재 제품 품질의 보증으로 재사용하지 않는다. 자세한 책임 경계는 [통합 자료](../02_design_knowledge/06_INTEGRATION_AND_WORK_PACKETS.md)에서 다룬다.
