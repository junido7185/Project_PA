## 자료 검증 결과

| 점검 | 결과 | 정확한 의미 |
|---|---|---|
| 기존 여섯 연구 문서 읽기 | 확인 | 최신 보존본의 전체 본문을 직접 읽음. 기존 문서 교체/수정 없이 후속 문서만 작성 |
| Canon/Identity 동일성 | 확인 | 1차 연구 고정 commit에서 다시 읽은 blob SHA가 기존 원장과 일치 |
| 공개 미디어 직접 확인 | 확인 | 공식 video/source URL과 실제 디코딩 프레임 확인. 검색 제목을 시각 증거로 사용하지 않음 |
| 상세 프레임 위치 | 확인 | V01 n=283/284·372/373 컷 경계, 동작/효과 표식의 인접 프레임을 직접 대조 |
| PTS·간격 계산 | PASS | 표의 프레임/시간을 ffprobe 결과로 대조. 52/60=0.866667, 3/60=0.050 계산 일치 |
| 무음 판정 | PASS | 공식 세 파일의 실제 float32 디코딩 샘플 전부 0. video의 muted 속성만으로 판정하지 않음 |
| 상대 문서 링크·Markdown fence | PASS | 문서 파일 링크가 묶음 안에서 존재, fence 짝/제목 공백 확인 |
| 범위와 주장 분류 | 검토 | 나무 벌목 한 경험만 분석. O/M/I/H/C/B/U 구별, 비용·UI·음향 공백을 H로 메우지 않음 |
| 기존 파일 보존 | 유지 | 기존 Canon·여섯 기준 문서에 쓰기 동작 없음. 새 후속 묶음만 추가 |

프레임 단계의 명칭은 사람이 적용한 시각 판독 기준이다. 자동화된 PTS 산술 검증이 그 의미나 원작 내부 이벤트를 입증하지 않는다. 원형/방사형 표식은 별도 효과 시스템의 증거가 아니다.

## 플레이 경험의 완료 경계

| 대상 | 상태 |
|---|---|
| 같은 짧은 숏의 두 타격 시각 표현 | 직접 관찰·부분 실측 완료 |
| 나무 발견→접근→선택→연속 벌목→소진→목재→획득→다음 행동 | **완전한 직접 증거 미확보** |
| 원작 벌목 원본 음향/HUD/실제 입력 | **미확인** |
| 원작 내부 구현·쿨다운·hitstop·리치 | **미확인, 수치 확정 없음** |
| 기존 U-01 | **OPEN 유지**. 바위 부분은 이번 범위 밖 |
| P.A. 상태/피드백/실패/검수 계약 | 구현 가설 문서 작성 완료 |
| P.A. Unity 실행·구현 품질·Q-DL01–15 | **이번 작업에서 미실행** |

파일 측정 PASS는 게임 손맛 PASS가 아니다. 이 연구가 추가하는 것은 제한된 시각 증거와 이를 독자적 상호작용 품질로 검증하는 설계 지식이다. 전체 원작 경험의 공백은 [추가 캡처 요구](DINKUM_LOGGING_CAPTURE_AND_GAPS_2026-10-12.md)에 정확히 남겼다.
