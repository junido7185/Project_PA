# 발표·제출 자료

- [Graduation](Graduation/): 실제 제출 PPT/PDF와 발표 대본. 같은 제목의 PPT와 PDF도 페이지·내용이 달라 각각 보존했다.
- [Demo](Demo/): 발표 시연 범위·과거 데모 지침. 현재 게임 설계나 개발 큐를 대신하지 않는다.
- [Evidence](Evidence/): 실제 구현 캡처와 검증 자료. 각 날짜·티켓의 상태만 증명한다.
- [Personal](Personal/): 게임 개발과 구분되는 수업·개인 제출 자료.
- [Drafts](Drafts/): 최종본에 없는 FR/NFR·로드맵을 가진 제안 템플릿 원본.

보호 대상인 P4 미커밋 자료는 [기존 경로](../Presentation/2026-09-09/P4/)에 남아 있다. 이번 정리에서 수정하거나 완료 증거로 승격하지 않았다.
