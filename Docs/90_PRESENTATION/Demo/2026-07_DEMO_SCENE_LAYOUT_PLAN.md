# DEMO_SCENE_LAYOUT_PLAN — 데모 장면 배치 계획 (현재 상태 기준)

작성: 2026-07-12 (Claude Fable 5)
대상 씬: `Assets/Scenes/Prototype_FirstDay.unity` (씬 파일 무수정 — 배치는 씬 정적 배치 + 런타임 사이드카 조합)

## 1. 배치 요소별 위치

### 상점 (화면 중심 포컬 포인트)
- 씬 정적: `Shop` + `ShopSlot_01~04` + `PA_MarketStall_Hub_Visual`(천막/기둥/랜턴/궤짝/가격표/간판).
- 런타임: `PA_ShopOpenSign`(영업 간판, `DayNightShopLoopController` 생성) + 이번 패스의 기둥/랜턴 드레싱.
- 의도: 어느 각도에서도 "줄무늬 천막 + 가격표"가 먼저 읽혀야 한다. 데모 카메라는 항상 상점을 프레임 중앙~우측에 둔다.

### 플레이어 시작 위치
- 씬 정적 `Player` — 상점 카운터 앞에서 시작. 온보딩 모달(개척자 등록) 종료 직후 상점과 첫 이주자 NPC가 한 화면에 들어온다.

### NPC (8명)
- `NPC_Bori_FirstSettler`(가이드), Farmer/Fisher/Miner/Chef/Tailor/Blacksmith/Carpenter — 씬 정적 배치 + NavMesh 배회.
- 손님 연출: Day 1 은 `PlayableDayScenarioController` 가 가격 확정 후 첫 손님을 상점으로 유도. Day 2+ 는 `CustomerArrivalController` 가 영업 시작 시 최대 2~3명을 순차 초대. 구매/거절 이유가 머리 위 말풍선으로 출력.

### 게시판/광장/분수/장식/배경
- 분수: `B11_PlazaFountain_Static` (씬 정적) — 광장 중심.
- 이번 패스 추가(런타임 `PA_DemoCozyDressing`): 분수 둘레 벤치 3, 상점~분수 동선 화단 4, 가로등 2, 상점 옆 궤짝 더미/통.
- 배경: 오두막 3채(`B10_Cottage_01~03`), 창고(`B09`), 무역항(`B12`) — 씬 정적.
- 마을 변화 코너: `PA_VillageCulture_Processed` (가공품 판매 다음날 아침에만 활성화, 상점 우측 후방).

### 채집 포인트 (낮 활동 동선)
- 상점 근처: Garden Prep Basket, Producer Drop Box (튜토리얼용).
- 마을 외곽 3방향: 숲길 채집(당근, 40°/9m), 해변 채집(생선, 130°/12m), 들판 채집(밀, 225°/10m).
- 이번 패스로 전부 나무 궤짝 + 작물 + 아이템 아이콘 빌보드로 표시 — "걸어가서 줍는" 동선이 눈에 보인다.

## 2. 데모 루트 이동 동선

```
[상점 앞 시작] → 첫 이주자 대화 (상점 옆)
   → Garden Basket 채집 (상점 바로 앞) → 숲길 채집 (외곽, 걷기 ~10초)
   → 상점 복귀: 진열 → 가격표 확정
   → (밤) 간판에서 영업 시작 → 손님 접근·말풍선·돈 증가 관람
   → 폰(P) 감사 앱 → F5 저장 → Day 요약
   → (다음날 아침) 상점 우측 가공품 코너 활성 확인
```

동선의 특징: 모든 목적지가 상점에서 왕복 20초 이내이고, 돌아올 때마다 상점이 다시 화면 중앙에 들어온다.

## 3. 왜 이 배치가 "완성된 게임처럼" 보이는가

1. **포컬 포인트 원칙** — 천막 상점이 항상 화면 중심에 있고, 나머지(분수/벤치/화단/가로등)는 상점을 둘러싸는 동심원 배치라 시선이 상점으로 모인다.
2. **소품 밀도의 층위** — 근경(궤짝/가격표) → 중경(벤치/화단/가로등) → 원경(오두막/무역항)의 3층 깊이가 생겨 "비어 보임"이 사라진다.
3. **동선 = 서사** — 채집 포인트가 3방향 외곽에 있어서 "낮에 마을을 돌아다닌다"가 화면에 그려지고, 밤에는 손님이 상점으로 모여 "운영한다"가 그려진다.
4. **정보의 세계 내 존재** — 가격표·간판·채집 아이콘·말풍선이 월드 안에 있어 UI 를 읽지 않아도 게임 상태가 보인다.
