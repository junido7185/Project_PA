# VC-001A - Next-Day Market Visual Change

Status: implemented and validated
Date: 2026-06-26

## Goal

Add one small next-day plaza or market visual change that reflects the previous day's sold product category, while preserving Project_PA's identity as a reverse supply-chain cozy management life-sim.

The feature is intentionally small: it proves that a product category sold through the shop can become visible in the village on the following day. It is not a new economy system, a save-system change, or a decorative clone of any reference project.

## Selected Category

Selected category: `Processed`

Reason:

- The current Day 1 default route sells `BreadLoaf`.
- `BreadLoaf` is an existing Project_PA item under the `Processed` category.
- `ShopSlot.TryPurchaseByNpc` already records sales through `SalesLogManager.RecordSale`.
- `VillageChangeSignalController` already reads recent sales and identifies `Processed` as a village direction category.

## Implementation

Added:

- `Assets/Scripts/VillageCultureVisualController.cs`
- `Assets/Editor/PA_VillageCultureVisualValidator.cs`

Runtime behavior:

- Creates a Project_PA-owned runtime sidecar named `PA_VillageCultureVisualController`.
- Creates a runtime visual root named `PA_VillageCulture_Processed`.
- The visual root is inactive at Day 1 start.
- A `Processed` sale creates a pending next-day change.
- The visual does not activate immediately after the sale.
- On the next `DayPreparation` phase, the visual appears as a warm processed-goods prep corner near the market hub.
- A short hint appears once and then hides itself.

No scene object from Project_D was used. The visual is made from Unity primitives and runtime materials only.
