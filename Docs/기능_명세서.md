### 12-B. Animator Controller

| 파라미터 | 타입 | 용도 | 상태 |
|---|---|---|:---:|
| `Speed` | Float | 0=Idle, 1=Walk (PlayerController에서 _currentSpeed/moveSpeed) | ✅ |
| `IsSitting` | Bool | 앉기/일어나기 전환 | ✅ |
| `WorkType` | Int | 0=없음, 1=파기, 2=자르기, 3=낚시, 4=가공 | ❌ |
| `IsTalking` | Bool | 대화 중 | ❌ |
| `GatherTrigger` | Trigger | 채집 1회 재생 | ❌ |

**Animator Controller 상태 머신 (NpcAnimatorController):**
```
[Any State] --GatherTrigger--> Gathering --exit--> Idle
Idle --Speed>0.1--> Walking --Speed<0.1--> Idle
Idle --IsSitting--> Sitting --!IsSitting--> Idle
Idle/Walking --WorkType>0--> Working(BlendTree by WorkType) --WorkType=0--> Idle
Idle --IsTalking--> Talking --!IsTalking--> Idle
```

**공유 전략:**
- C-01(플레이어) Avatar 생성 → C-02~09는 "Copy From Other Avatar"로 공유
- NpcAnimatorController 1개로 모든 Humanoid NPC 공유 가능
