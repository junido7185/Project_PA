# Project P.A. Implementation Roadmap

최종 갱신: 2026-07-27

세부 장기 단계는 `AI_WORKFLOW/07_FULL_GAME_ROADMAP/FULL_GAME_COMPLETION_ROADMAP.md`가 원본이다. 이 문서는 플레이어가 체감하는 연결 단위만 추린다.

## 현재 체크포인트

### S4 — Tier 1 실내 잡화점 진화

- Tier 0에서 실내 문 잠금과 다음 목표 표시.
- Tier 1 승급 시 문·간판·조명·해금 안내 전환.
- 기존 `TierService.currentTier` 저장을 이용해 로드 후 공간 상태 복원.
- Tier 1에서 입장 → 실내 진열 → 가격 → 손님 구매 → 퇴장 경로 유지.

## 다음 체크포인트 순서

1. 3일 플레이 경로의 실제 단절 감사: Day 1 종료부터 Day 3 정산까지 플레이어 입력으로 이어지는지 확인하고 막힌 한 구간만 연결한다.
2. 밤 손님 시간 창 구현 완료·실플레이 대기: 실제 시간표는 보존하고 Rest 주민에게만 외부·실내 영업 방문 lease를 부여했다. 안전 Unity 경로에서 18:30/20:30/22:30 유입과 23:00 복귀를 확인한다.
3. 구매/거절 일일 통계 구현 완료: Task 034가 성공 판매·거절을 정산과 다음 날 가격 조언에 연결했다. 장기 저장은 Task 055 승인 대기다.
4. 낮 활동 1차 구현 완료·실플레이 대기: 낚시·광질·고정 밭·주민 요청이 실제 재고/준비 선택으로 연결됐다.
5. 진행 변화 4카테고리 구현·실플레이 대기: Processed/Raw/Utility/Luxury가 실제 에셋 기반 다음 날 변화와 v10 저장을 갖췄다. 안전 Unity 확인 뒤 실제 시설/주민 효과를 순차 연결한다.
6. Task 112 2주차 운영 캠페인 구현 완료·실플레이 대기: Day 8~14가 보관→가공→채용→상품 카테고리→Tier 1→마을 변화→상품 다양화의 실제 상태 목표로 이어진다.
7. Task 114 첫 달 운영·완주 구현 완료·실플레이 대기: Day 15~30이 기존 성장 상태를 순환하고 Day 30 정산에서 저장 후 종료 또는 Day 31 계속을 선택한다.
8. Task 115 Tier 1 Forge 가치사슬 구현 완료·실플레이 대기: B07을 기존 Tier 1 데이터와 정합하고 Day 23/24를 정확한 ToolSet+혼합 판매로 연결했다. Tier 1 장부→진열대 회수→3×2 배치→IronBar/ToolSet 제작→판매를 확인한다.
9. 최종 통합: 3일/2주차/첫 달 대표 실제 플레이, 저장 종료/재실행, UI·사운드·시각 일관성, Windows 빌드.

각 체크포인트는 하나의 플레이어 경험, 최소 컴파일/핵심 스모크, 상태 문서 갱신으로 닫는다. 전체 회귀와 미세 폴리시는 핵심 경로가 연결된 뒤 묶어서 수행한다.
