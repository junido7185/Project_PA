# CODEX_VERIFY_PROMPT

> 사용 상황: 직전 작업 결과를 **코드 수정 없이** 검증한다. 커밋 전 점검.
> 아래 전체를 복사해 Codex에 붙여넣는다.

---

너는 Unity 게임 Project P.A.의 검수 작업자다. 이번 세션에는 **코드를 수정하지 않는다.** 직전 작업의 결과만 검증한다.

## 먼저 읽을 문서

1. `AGENTS.md`
2. `AI_WORKFLOW/04_VERIFICATION/VERIFICATION_RULES.md`
3. `AI_WORKFLOW/03_TASKS/ACTIVE_TASK.md` (또는 직전 `DONE_TASKS.md` 항목)
4. `AI_WORKFLOW/02_AGENT_RULES/AI_SLOP_PREVENTION.md`

## Project P.A. 정체성 요약

낮 마을 생활 + 밤 잡화점 운영의 3D 코지 라이프 심. "내가 판 물건이 마을을 바꾼다." 완성 게임이 목표.

## 이번 프롬프트의 목적

- 직전 작업이 실제로 동작하는지, 데모 흐름을 깨지 않았는지 검증하고 결과를 보고한다.

## 허용되는 작업

- 컴파일 확인, 검증기 실행, Play 스모크, 로그/콘솔 확인, 문서(검증 결과) 기록.

## 금지되는 작업

- 모든 코드/씬/에셋 수정 (버그를 찾아도 고치지 말 것 → BUG_LOG에 기록만).
- git 커밋/푸시.
- 아래 AI 슬롭 방지 규칙 전부.

## 작업 전 보고 양식

- 검증 대상 Task ID/변경 파일.
- 사전 점검: Unity Editor 열림 여부(열림이면 batchmode 금지), 최신 크래시 리포트(Unity 실행 시).

## 작업 후 보고 양식 (VERIFICATION_RULES.md 양식)

- 컴파일: [통과/실패/보류] (증거)
- 검증기: [이름 + 결과] (증거)
- 상점 루프 / 저장·로드 / 마을 변화: [결과 또는 해당 없음]
- 발견했지만 고치지 않은 문제: BUG_LOG에 기록한 항목
- 확인 못 한 것: 이유 + 사람 확인 방법

## 검증 기준

- 실제 실행 결과가 있을 때만 "통과". 추정 금지. 테스트 안 한 것을 했다고 말하지 않는다.

## 실패 시 멈추는 조건

- 검증기가 2회 같은 이유로 실패하면 중단하고 `BUG_LOG.md` 기록 후 사람 판단 요청.
- 크래시 발생 시 즉시 중단.

## CHANGELOG_AI.md 갱신 규칙

- 검증 결과를 `AI_WORKFLOW/05_LOGS/CHANGELOG_AI.md`에 짧게 기록(선택). 문제 발견 시 `BUG_LOG.md`에 반드시 기록.

## HANDOFF_FOR_CODEX.md 갱신 규칙

- 검증으로 우선순위/위험이 바뀌면 `HANDOFF_FOR_CODEX.md` 갱신.

## AI 슬롭 방지 규칙 (항상)

- 전체 시스템 재작성 금지 · 기존 작동 기능 삭제 금지 · 게임 장르 재해석 금지 · 감성 서사/철학/다크 톤 변경 금지 · 대형 리팩터링 금지 · 한 번에 여러 작업 금지 · 요청 없은 외부 패키지 금지 · 씬/프리팹/SO 임의 대량 수정 금지 · PlayerController/SaveManager/InventoryManager 임의 재작성 금지 · 컴파일 확인 없이 완료 선언 금지 · 테스트 안 한 걸 했다고 보고 금지 · 실패를 성공처럼 말하기 금지 · 프로토타입 완성만 목표로 축소 금지.
