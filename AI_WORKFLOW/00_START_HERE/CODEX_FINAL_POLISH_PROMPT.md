# CODEX_FINAL_POLISH_PROMPT

> 사용 상황: 포트폴리오/시연용 최종 마무리. **코드 대수술 금지.** UI 문구, 데모 체크리스트, 기술 설명 정리 위주.
> 아래 전체를 복사해 Codex에 붙여넣는다.

---

너는 Unity 게임 Project P.A.의 최종 마무리 담당이다. 코드를 크게 건드리지 마라. 다듬기(문구·문서·표현)와 아주 작은 표시 개선만 한다.

## 먼저 읽을 문서

1. `AGENTS.md`
2. `AI_WORKFLOW/03_TASKS/DEMO_SCRIPT_5MIN.md`, `DEMO_DAY_CHECKLIST.md`
3. `AI_WORKFLOW/01_IDENTITY/PROJECT_PA_IDENTITY.md` (톤 유지)
4. `AI_WORKFLOW/04_VERIFICATION/VERIFICATION_RULES.md`

## Project P.A. 정체성 요약

낮 마을 생활 + 밤 잡화점 운영의 3D 코지 라이프 심. "내가 판 물건이 마을을 바꾼다." 코지·밝은 톤 유지.

## 이번 프롬프트의 목적

- UI 문구 다듬기, 데모 체크리스트 정리, 기술 설명(발표/포트폴리오) 문서화. 게임을 "완성 게임을 향한 안정 슬라이스"로 보이게 마무리.

## 허용되는 작업

- UI 텍스트/문구 소규모 조정(레이아웃 대변경 아님).
- 데모/발표 문서 정리, 조작 안내, 기술 설명 문서 작성.
- 아주 작은 표시 버그 수정(1파일 수준).

## 금지되는 작업

- 코드 대수술, 새 기능, 밸런스 변경, 리팩터링, 씬/프리팹 대량 수정.
- 감성 서사/철학/다크 톤으로의 문구 변질(코지 톤 유지).
- 아래 AI 슬롭 방지 규칙 전부.

## 작업 전 보고 양식

- 다듬을 대상(문구/문서/작은 표시) 목록 / 최소 변경 계획.

## 작업 후 보고 양식

- 변경한 문구/문서/파일, 톤 유지 확인, 데모 흐름 유지 확인.
- 확인 못 한 것(특히 1920x1080 가독성은 사람 확인 필요로 표시).

## 검증 기준

- 컴파일 통과, 데모 루트 유지, 문구가 코지 톤·정체성과 일치.
- UI 최종 가독성은 사람 판정 항목으로 표시.

## 실패 시 멈추는 조건

- 문구 변경이 코드 구조 변경을 부르면 중단(그건 폴리시가 아님).
- 2회 실패 시 `BUG_LOG.md` 기록 후 보고.

## CHANGELOG_AI.md 갱신 규칙

- 변경 시 `CHANGELOG_AI.md`에 "final polish"로 기록.

## HANDOFF_FOR_CODEX.md 갱신 규칙

- 제출/시연 완료 상태를 `HANDOFF_FOR_CODEX.md`에 반영.

## AI 슬롭 방지 규칙 (항상)

- 전체 시스템 재작성 금지 · 기존 작동 기능 삭제 금지 · 게임 장르 재해석 금지 · 감성 서사/철학/다크 톤 변경 금지 · 대형 리팩터링 금지 · 한 번에 여러 작업 금지 · 요청 없은 외부 패키지 금지 · 씬/프리팹/SO 임의 대량 수정 금지 · PlayerController/SaveManager/InventoryManager 임의 재작성 금지 · 컴파일 확인 없이 완료 선언 금지 · 테스트 안 한 걸 했다고 보고 금지 · 실패를 성공처럼 말하기 금지 · 프로토타입 완성만 목표로 축소 금지.
