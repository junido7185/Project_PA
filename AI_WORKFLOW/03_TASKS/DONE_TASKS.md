## 기록 규칙

- **Task ID**: `TASK_QUEUE.md`의 번호 (예: Task 001).
- **검증 결과**: 실제 실행한 것만. 못 한 항목은 "미검증"으로. 추정 금지.
- **커밋 해시**: 사용자가 커밋한 경우만 기입. 미커밋이면 "미커밋".
- **남은 위험**: 이 작업이 남긴 잠재 문제나 후속 확인 필요 사항.
- **다음 작업**: 이 작업의 후속으로 권장되는 Task ID.
