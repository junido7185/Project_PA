# 작업 선택 절차

현재 작업 큐는 [INTEGRATION_QUEUE](../../Docs/00_CURRENT/INTEGRATION_QUEUE.md) 하나다. 마지막 사용자 지시와 승인 범위를 확인하여 한 bounded ticket만 수행한다.

과거 TASK_QUEUE와 sprint 계획은 [상세 backlog](../../Docs/02_IMPLEMENTATION/Backlog/), 옛 ACTIVE_TASK는 [보관 문서](../../Docs/99_ARCHIVE/Superseded/)에 있다. 해당 파일의 ACTIVE는 현재 실행 승인이 아니다.
