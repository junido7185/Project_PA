# PROJECT_PA_SCOPE — 완성까지 가는 범위 관리

작성: 2026-07-09
지위: **프로토타입 범위 문서가 아니다.** Project P.A.를 완성 게임까지 끌고 가기 위한 단계별 범위 정의다. 각 단계의 시기·순서는 `../07_FULL_GAME_ROADMAP/FULL_GAME_COMPLETION_ROADMAP.md` 참조.

## 1. Full Game Target — 완성 게임이 갖춰야 할 최종 구조

플레이어가 수십 시간 동안 반복해도 성립하는 코지 라이프+상점 경영 게임:

- **낮 생활 4계열** (채집·낚시·광질·농사) + 주민 의뢰 + 마을 꾸미기가 모두 상점 재고로 연결됨
- **가공 체인**: 원자재 → 가공품 → 고급품의 부가가치 경로, 워크샵/전문가 NPC
- **밤 영업**: 주민+관광객 손님 계층, 성향·예산·평판 기반 구매, 붐비는 밤의 연출
- **마을 변화**: 판매 카테고리별 마을 풍경·시설·주민 행동·문화의 가시적 변화 (핵심 차별점)
- **성장 구조**: 가게 확장(좌판→상점→그 이상), 티어/감사, 시설 해금, NPC 고용/자동화
- **NPC 생태**: 스케줄·직업·관계·MBTI 성향이 경제와 생활 양쪽에 작동
- **장기 지속**: 계절/주간 수요 변화, 견고한 저장/불러오기, 멀티 주차 진행, 밸런스
- **완성도**: 안정된 빌드, 사운드, 아트 일관성, 온보딩

## 2. Graduation Demo Milestone — 졸업 발표 시연 목표

완성 게임의 **부분집합**을 안정적으로 보여준다. 별도 분기 빌드 금지.

- Day 1~3 슬라이스가 끊기지 않고 돈다 (기준: `PROJECT_PA_CORE_SLICE_PLAN.md`)
- 시연 라인: 낮 채집 → 진열·가격 → 밤 영업·구매/거절 피드백 → 정산 → **다음날 마을 변화 1종**
- 1920x1080에서 HUD/말풍선/정산창 가독성 확보, 한국어 폰트 정상
- Windows 빌드 실행 가능 + 시연 실패 대비 녹화본
- 발표 자료와 시연 시나리오 (기존: `Docs/Presentation` 예정 폴더 및 `README.md` 데모 루트)

## 3. Vertical Slice Target — 핵심 재미 압축 구간

완성 게임의 재미를 30~40분 안에 증명하는 구간. 졸업 시연보다 깊고, 완성 게임보다 좁다.

- Day 1~7 (1주차) 플레이: 매일 다른 낮 활동 조합이 가능
- 가공 1체인 이상 (원자재 → 가공품 판매의 이득 차이 체감)
- 손님 2계층 이상 + 성향별 구매 차이가 눈에 보임
- 마을 변화 신호 2~3종 (카테고리별로 다른 변화)
- 가게 확장 1단계 (슬롯 증가 또는 시설 해금)
- 저장/불러오기로 이어하기 성립

## 4. MVP Stabilization Target — 첫 안정화 기준 (현재 단계)

임시 프로토타입이 아니라 **완성으로 가는 첫 안정 지반**. "여기서부터는 다시 안 갈아엎는다"의 기준선.

- [x] Day/Night 페이즈 루프 + 영업 게이트
- [x] 낮 채집 → 진열 → 가격 → NPC 구매 → 정산 한 바퀴
- [x] 마을 변화 신호 1종 (VC-001A)
- [ ] 배치 검증기 통과 재확인 (Unity Editor 열림으로 보류 중인 2종 포함)
- [ ] 1920x1080 수동 가독성 확인 (사람)
- [ ] VC-001A 포함 체크포인트 커밋으로 클린 baseline 확보
- [ ] 저장 v8 스키마의 세이브→로드 왕복 확인

## 5. Post-Demo Expansion — 시연 이후 확장

졸업 시연 확정(Demo Lock) 후 착수하는 것들: 낚시/광질/농사 실装 심화, 가공 체인 확대, 관광객 계층, 계절 시스템, 가게 확장 2단계+, 고용/자동화 UI, 평판/단골, 사운드 전면 도입, 밸런스 패스.

## 6. 하지 말아야 할 과욕 기능 (승인 없이 착수 금지)

- 멀티플레이/클라우드 저장 (Docs/04는 Deferred)
- 오픈월드급 섬 확장, 절차 생성 지형
- 새 장르 붙이기 (전투, 던전, 로그라이크 등)
- 풀 보이스, 시네마틱 컷씬
- 모바일/크로스플랫폼 대응
- 저장 시스템 전면 재설계 (추가 확장만 허용, v7→v8 패턴)
- UI 프레임워크 교체, 외부 에셋 도입

## 7. 나중에 해도 되는 기능 (Full Game 대상이지만 지금 아님)

- 계절/날씨, 축제 이벤트
- NPC 관계 심화(선물/호감 이벤트), 히든 도면
- 상점 인테리어 꾸미기, 테마 코너 연출
- 도전 과제, 통계 화면, 사진 모드
- 밸런스 세밀 조정 (Vertical Slice 후)

## 8. 절대 버리면 안 되는 핵심 재미

어떤 단계 조정·범위 축소가 있어도 아래는 제거·약화 금지:

1. **낮에 직접 몸을 움직여 재료를 얻는 생활감** — 걸어가서 줍고, 낚고, 캐는 감각
2. **가격을 내가 정하고 손님이 판단하는 긴장** — 구매/거절 이유가 읽히는 것
3. **"내가 판 물건이 마을을 바꾼다"** — 정산 다음 날 마을에서 보이는 변화
4. **작은 좌판에서 시작해 커지는 성장 서사** — 티어/확장/해금의 기대감
5. **코지한 톤** — 밝고 따뜻한 로우폴리 마을
