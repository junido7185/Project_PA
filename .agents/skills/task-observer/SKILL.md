# Optional Task Observer

Use only for a requested methodology/skill review or a clear repeated friction investigation. Do not run a startup scan, review trigger or observation report during ordinary game production. Preserve existing observation records at `.agents/task-observer/skill-observations/`.

When a review is requested, load only the relevant procedure in `references/observer-manual.md` and its references. The old mandatory activation/session-start text in that preserved manual is superseded by this entry and AGENTS.md. Do not create another state/task list.
